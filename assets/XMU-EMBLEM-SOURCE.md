# Application emblem

`xmu-university.png` is a PNG conversion of the 150 × 150 emblem shown on the official Xiamen University [school identity page](https://www.xmu.edu.cn/sdgl/xxbs.htm), retrieved 2026-11-07. The artwork was not redrawn. The PNG is the runtime application icon; ICO and Android launcher sizes are generated by `scripts/render_brand_assets.py`.

Room-name aliases used in the Android timetable link are supported by [XMU METC public teaching services](https://metc.xmu.edu.cn/fwzn/ggjxfw.htm) and the [School of Informatics building naming notice](https://informatics.xmu.edu.cn/info/1103/12447.htm). Coordinates remain the existing GCJ-02 building presets; the notices only establish name correspondence.
